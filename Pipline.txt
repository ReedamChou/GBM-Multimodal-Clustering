Multi-modal clustering combining MRI sub-region ratios, brain lobe location, and clinical variables identifies a high-risk GBM subtype characterised by temporal lobe dominance, high NC/EN ratio, and short survival

Step 1: Load and audit UCSF-PDGM
Load the CSV in Python (pandas). Check every column for missing values and handle them using suitable methods. Handle nifti images according to your requirements. Check for and perform other data preprocessing steps you feel are needed. Remember data preprocessing is an important step. It will ensure cleaner, more reliable input data, leading to better model performance and more accurate results.
Step 2: Extract imaging features from NIfTI
Per patient: the dominant brain lobe (frontal, temporal, parietal, or occipital), per-lobe ED/EN/NC ratios (12 ratio columns across 4 lobes), global NC/EN ratio, global ED/EN ratio, global ED total ratio, and tumor burden index. Save everything to a csv file, with one row per patient. Run it once and save the output so you never have to repeat it.
Step 3: Build the master feature table
Merge above calculated csv with the clinical CSV on patient ID. Your merged table now has both imaging and clinical columns. Then do three things in order.
First, handle missing values. For continuous features like age, impute with the column median. For categorical features like MGMT status, impute with the mode (most common value), or create a separate "unknown" category if missingness is above 10%. Try not to remove any patient.
Second, encode categorical variables. Convert the dominant lobe column into four binary columns using one-hot encoding (frontal, temporal, parietal, occipital each become 0 or 1). Convert sex, MGMT, and IDH to 0/1 integers.
Third, standardise all continuous features using z-score normalisation, subtract the mean and divide by the standard deviation. This ensures no single feature dominates the clustering similarity calculation because of its scale. Critically, do not include OS or the censoring flag in the clustering feature set, these are outcome variables, not inputs. Save the scaler object so you can apply the exact same transformation to the test set later.
Step 4: Split into train (70%) and test (30%)
Use stratified splitting to ensure both sets have similar proportions of MGMT-methylated patients and similar OS distributions. After splitting, apply the scaler, fit it on the train set only, then transform both train and test sets separately. Never fit the scaler on the test set or on the combined data. Set the test aside and don’t touch it now. This is the most commonly violated rule in clustering studies, people characterise their clusters and then check if the pattern holds on the same data they clustered, which is circular.
Step 5: Spectral clustering on the train set
Using sklearn.cluster.SpectralClustering, run clustering with k set to 2, 3, 4, 5, and 6. For each k, compute the silhouette score using sklearn.metrics.silhouette_score. Record the score for each k and pick the value with the highest score. A plot of silhouette score versus k (called an elbow plot) is a standard figure in clustering papers.
After picking the best k, save the cluster labels assigned to each training patient. Also compute the centroid of each cluster, the mean feature vector of all patients in that cluster. You will use these centroids in Step 7 to assign test patients.
Step 6: Characterise clusters in the train set
For each cluster, compute the following and put them in a summary table: median OS with interquartile range, percentage MGMT methylated, percentage IDH mutant, mean NC/EN ratio, mean ED/EN ratio, mean TBI, dominant lobe (the lobe that appears most frequently), and mean age.
Then run three statistical tests. For survival differences across clusters: plot Kaplan-Meier curves for all clusters on the same axes and run a log-rank test, you want p < 0.05. For continuous feature differences: run a Kruskal-Wallis test for each continuous feature across clusters. For categorical features: run chi-square tests for MGMT status and lobe distribution. Correct all p-values for multiple comparisons using the Benjamini-Hochberg method.
Inspect the summary table and identify your high-risk cluster. It should show the combination of temporal lobe dominance, high NC/EN ratio, low median OS, and low MGMT methylation rate. Give it a descriptive label rather than calling it "Cluster 2", something like "temporally-dominant high-necrosis subtype."
Step 7: Validate on the held-out test set
Now you open the test set. Apply the same z-score scaler (the one fitted on the train set) to the test features. Then assign each test patient to the nearest cluster centroid using Euclidean distance. Now check two things. First, do the same cluster proportions roughly hold, is the "high-risk" cluster still approximately the same size relative to the others? Second, do the survival differences replicate? Plot Kaplan-Meier curves for the test set patients split by their assigned cluster label and run another log-rank test. If the high-risk cluster still shows significantly shorter OS in the test set, you have internal validation of your finding. If the survival separation disappears in the test set, the cluster was overfitted to the training data and the finding is not reliable, this is exactly why the split was necessary.
Also check that the high-risk test cluster still shows temporal dominance and high NC/EN ratio, these imaging characteristics should replicate even if the survival p-value is slightly weaker due to smaller sample size.
Step 8: Report and visualise
The paper needs five key figures:
A feature heatmap- rows are features, columns are clusters, colour is the z-scored mean value per cluster. This is the single most informative figure in a clustering paper because it shows at a glance what defines each cluster. Use seaborn.heatmap.
Kaplan-Meier curves- one plot for train set, one for test set, both showing all clusters with shading for confidence intervals and the log-rank p-value annotated. Use lifelines.KaplanMeierFitter.
A lobe distribution bar chart- stacked or grouped bars showing the percentage of patients in each cluster whose dominant lobe is frontal, temporal, parietal, or occipital.
A silhouette score elbow plot- showing your k selection process transparently.
A cluster summary table- median OS, MGMT rate, NC/EN mean, dominant lobe, and n per cluster, for both train and test sets side by side.
